## Что это за проект

Сайт имитирует рабочий терминал бюро **AEON** из вселенной видеоигры SIGNALIS (Нация Евзан). Пользователь «входит» в систему под уровнем допуска **0**, листает официальные сводки и постепенно повышает уровень вплоть до **IV (EYES ONLY)**. Чем выше допуск, тем больше информации открывается: снимается цензура со строк, появляются закрытые вкладки досье, а официальная пропаганда начинает расходиться с внутренними данными.

Весь сайт — **один файл `index.html`**: ни сборщика, ни фреймворков, ни внешних библиотек и шрифтов. Это сознательное решение — меньше зависимостей, меньше поверхность атаки, проще деплой.

## Что умеет терминал

**Восемь разделов**

| № | Раздел | Содержимое |
| :---- | :---- | :---- |
| I | Главная сводка | Официальные бюллетени и общая картина |
| II | Система AEON | Устройство сети и её ведомств |
| III | Программа Penrose | Интерактивная SVG-схема корабля с шестью отсеками и четырьмя статусами миссии |
| IV | Rotfront | Региональный архив: локации, общество, хронология, документы |
| V | База реплик | Десять досье биомеханических кадров с поиском и вкладками |
| VI | Архив достижений | Двенадцать «заслуг государства» с фильтрацией |
| VII | Директивы | Восемь распоряжений, часть из них засекречена |
| VIII | Терминал / аудит | Консоль логов, проверка целостности архива, журнал действий сессии |

**Механики**

- **Пять уровней допуска (0–IV).** Всего в архиве 25 документов; сколько из них доступно, показывает счётчик в панели управления.  
- **Досье реплик с четырьмя вкладками**, которые открываются по мере роста допуска: официальная сводка → техдокументация → психологический профиль → засекреченное досье.  
- **Модальные окна документов.** Если допуска не хватает, терминал отвечает `ACCESS DENIED` и подсказывает нужный уровень.  
- **Загрузка в стиле BIOS** с прогресс-баром, кнопкой пропуска и возможностью перезапуска.  
- **Живая телеметрия:** часы системы, поток логов, журнал обращений к архиву.  
- **Переключатель ЭЛТ-помех** (кнопка в панели): отключает сканлайны, «полоски телевизора» и мерцание.

## Визуальный стиль

Палитра — тёмный фон, «бумажные» панели, красный и янтарный акценты. Поверх интерфейса работает слой имитации кинескопа:

- горизонтальные строки развёртки и бегущая «рулонная» полоса на фоне;  
- светящаяся линия-помеха, проходящая по экрану сверху вниз;  
- лёгкое мерцание и дрожание кадра;  
- плавные переходы у кнопок, вкладок, карточек и модальных окон; появление элементов каскадом.

Уважается системная настройка `prefers-reduced-motion`: при ней движущиеся эффекты отключаются.

## Развёртывание в AWS

Публикация настроена по схеме *push → автоматическая выкатка*:

1. Исходник лежит в ветке `main` репозитория GitHub.  
2. В консоли AWS открыт **Amplify Hosting**, приложение подключено к этому репозиторию через GitHub App.  
3. Команда сборки пуста, потому что сайт статический; директория публикации — корень проекта.  
4. Каждый `git push` в `main` запускает новое развёртывание. Amplify сам выпускает сертификат и раздаёт сайт по HTTPS.

Скриншоты каждого шага приведены в отчёте.

## Оценка киберрисков

Статический сайт без бэкенда исключает целые классы угроз: нет серверной ОС под управлением владельца, базы данных, форм ввода и открытых портов. Остаются риски, связанные в основном с цепочкой поставки и настройкой облака.

| Угроза | Серьёзность | Чем опасна | Как закрыта или как закрыть |
| :---- | :---: | :---- | :---- |
| Захват аккаунта GitHub или AWS | Высокая | Подмена `index.html` и мгновенная выкатка на продакшн | 2FA на обоих аккаунтах, защита ветки `main`, минимальные права у GitHub App |
| Внедрение вредоносного кода через коммит или PR | Средняя | Скрытый скрипт попадёт на публичный сайт | Обязательный review, запрет прямых пушей в `main`, просмотр диффов |
| Утечка секретов в истории Git | Низкая | Ключи в публичном репозитории | В проекте секретов нет; при их появлении — переменные окружения Amplify и `.gitignore` |
| Отказ в обслуживании (L7) | Средняя | Недоступность сайта, расход лимитов трафика | Кеш на CloudFront, AWS Shield Standard, при необходимости AWS WAF и бюджетные алерты |
| Перехват трафика | Низкая | Подмена содержимого по пути к пользователю | HTTPS (TLS 1.2+) и управляемый сертификат |
| Отсутствие защитных HTTP-заголовков | Низкая | Clickjacking, MIME-sniffing, XSS при будущем расширении | Задать в Amplify `Content-Security-Policy`, `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy` |
| Лишние данные в публичной копии кода | Низкая | Раскрытие личных данных автора | Перед публикацией проверять файл на ФИО, почту, группу |

> Часть интерфейса использует inline-обработчики (`onclick`), поэтому строгая CSP потребует либо `unsafe-inline`, либо переноса обработчиков в `addEventListener`. Это естественный следующий шаг по усилению защиты.

## Дисклеймер

Проект учебный и некоммерческий. Вселенная, названия, термины и сюжетные элементы принадлежат создателям игры **SIGNALIS** (rose-engine). Все тексты архива написаны автором как фанатская стилизация. Разделы с пометкой о спойлерах раскрывают сюжетные детали игры.
