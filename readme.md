## Что это за проект

Сайт имитирует рабочий терминал бюро **AEON** из вселенной видеоигры SIGNALIS (Нация Евзан). Пользователь «входит» в систему под уровнем допуска **0**, листает официальные сводки и постепенно повышает уровень вплоть до **IV (EYES ONLY)**. Чем выше допуск, тем больше информации открывается: снимается цензура со строк, появляются закрытые вкладки досье, а официальная пропаганда начинает расходиться с внутренними данными.

Весь сайт — **один файл `index.html`**: ни сборщика, ни фреймворков, ни внешних библиотек и шрифтов. Это сознательное решение — меньше зависимостей, меньше поверхность атаки, проще деплой.

Помимо основного терминала в состав проекта входит автономное мобильное веб-приложение **`penrose_512_terminal.html`** (**PENROSE-512 // Personal Flight Terminal**) — личное бортовое устройство инженерной Реплики **LSTR-512 (Elster)**, выполненное по тому же принципу единого самодостаточного HTML-файла.

## Что умеет терминал

**Восемь разделов**

| № | Раздел | Содержимое |
| :---- | :---- | :---- |
| I | Главная сводка | Официальные бюллетени и общая картина |
| II | Система AEON | Устройство сети и её ведомств |
| III | Программа Penrose | Интерактивная SVG-схема корабля с шестью отсеками и четырьмя статусами миссии |
| IV | Rotfront | Региональный архив: локации, общество, хронология, документы |
| V | База реплик | Десять досье биомеханических кадров с поиском и вкладками |
| VI | Архив достижений | Двенадцать «заслуг государства» с фильтрацией |
| VII | Директивы | Восемь распоряжений, часть из них засекречена |
| VIII | Терминал / аудит | Консоль логов, проверка целостности архива, журнал действий сессии |

**Механики**

- **Пять уровней допуска (0–IV).** Всего в архиве 25 документов; сколько из них доступно, показывает счётчик в панели управления.  
- **Досье реплик с четырьмя вкладками**, которые открываются по мере роста допуска: официальная сводка → техдокументация → психологический профиль → засекреченное досье.  
- **Модальные окна документов.** Если допуска не хватает, терминал отвечает `ACCESS DENIED` и подсказывает нужный уровень.  
- **Загрузка в стиле BIOS** с прогресс-баром, кнопкой пропуска и возможностью перезапуска.  
- **Живая телеметрия:** часы системы, поток логов, журнал обращений к архиву.  
- **Переключатель ЭЛТ-помех** (кнопка в панели): отключает сканлайны, «полоски телевизора» и мерцание.

## Мобильное веб-приложение: PENROSE-512 // Personal Flight Terminal (`penrose_512_terminal.html`)

Отдельный модуль проекта — личный бортовой терминал Реплики **LSTR-512 (Elster)** и офицера-радиста **Арианы Йонг** на разведывательном судне **Penrose-512**. В отличие от государственного архива `index.html`, это устройство принадлежит непосредственно участнице экспедиции и изменяется вместе с историей корабля.

**Пять сюжетных состояний (States I–V)**

| Состояние | Циклы | Статус систем | Что меняется в устройстве |
| :---- | :---- | :---- | :---- |
| **I — PREPARATION** | `0000–0019` | `NOMINAL (99.4%)` | Предстартовая выверка и первые циклы полёта. Спокойный функциональный интерфейс, уставные инструкции, штатная телеметрия. |
| **II — EARLY MISSION** | `0240–0895` | `NOMINAL (94.1%)` | Повседневная вахта в космосе. В личном дневнике LSTR-512 появляются записи о быте на корабле, живописи, музыке и общении с Арианой Йонг. |
| **III — DEGRADATION** | `1640–2840` | `DEGRADED (71.2%)` | Расхождение официальных сводок (`НОРМА`) с показаниями датчиков реактора (`УТЕЧКА ХЛАДАГЕНТА`), первые сбои буфера памяти и следы лучевой болезни. |
| **IV — SIGNAL LOST** | `3000–3690` | `CRITICAL (38.6%)` | Получение Директивы Фазы III (3000 циклов), потеря связи с Ротфронтом, перевод Арианы в криокапсулу отсека №04, изменение ранее прочитанных записей. |
| **V — MEMORY FRAGMENTATION** | `5124 // ∞` | `FRAGMENTED (12.0%)` | Глубокое нарушение целостности архива, наложение памяти Винеты и шахт S-23 «Серпински», реконструкция повреждённых фрагментов и частота `155.000 kHz`. |

**Пять вкладок и возможности `penrose_512_terminal.html`**

- **`STATUS`** — бортовое удостоверение с невозможным треугольником Пенроуза, показатели матрицы и среды, пять контуров допуска (`FLIGHT`, `ENGIN`, `CMD/MED`, `RESTRICT`, `RECOVER`), личное техническое дело LSTR-512, журнал операций и настройки симуляции.
- **`PENROSE`** — интерактивная SVG-схема судна Penrose-512 с шестью отсеками (`01. Рубка`, `02. Радиоузел`, `03. Каюта офицера`, `04. Криокапсула`, `05. Отсек LSTR`, `06. Реактор ТЯР`), паспорт миссии, регламент работ и хронология полёта с сопоставлением официальных отчётов и реальности.
- **`LOG`** — личный дневник и архив памяти LSTR-512 с поиском, фильтрами, избранным (`★`), журналом контроля версий мутировавших записей и интерактивным восстановлением повреждённых фрагментов, а также отдельный подраздел об **Ариане Йонг**.
- **`RADIO`** — бортовой приёмопередатчик `PKF-512` (`050–160 kHz`) с осциллографом на `<canvas>`, опциональным звуковым синтезатором (Web Audio API) и семью сюжетными частотами (`065`, `082`, `096`, `114`, `132`, `148`, `155 kHz`).
- **`ARCHIVE`** — система документов по девяти категориям с метками каноничности (`CANON`, `RECON`, `INTERP`), технический справочник Реплик и бортовая консоль CLI (`HELP`, `STATUS`, `DIAG`, `COMPARE`, `RESTORE`, `PROMISE`, `PWA`, `CLEAR`).
- **Сохранение и режимы:** поддерживаются последовательный **Сюжетный режим** и **Режим демонстрации** (свободное переключение состояний I–V), сохранение прогресса в `localStorage` и установка на главный экран смартфона (PWA через `manifest.json`, `sw.js` и `penrose-icon.svg`).

## Визуальный стиль

Палитра — тёмный фон, «бумажные» панели, красный и янтарный акценты. Поверх интерфейса работает слой имитации кинескопа:

- горизонтальные строки развёртки и бегущая «рулонная» полоса на фоне;  
- светящаяся линия-помеха, проходящая по экрану сверху вниз;  
- лёгкое мерцание и дрожание кадра;  
- плавные переходы у кнопок, вкладок, карточек и модальных окон; появление элементов каскадом.

Уважается системная настройка `prefers-reduced-motion`: при ней движущиеся эффекты отключаются.

## Запуск локально и на мобильном устройстве

Сборка не нужна — и основной портал (`index.html`), и мобильный терминал (`penrose_512_terminal.html`) работают напрямую в браузере.

### 1. Локальный запуск на компьютере

```bash
git clone https://github.com/shiowhynasvaiblowa/Signalis-AEON-Network.git
cd Signalis-AEON-Network

# Способ А: открыть файлы двойным кликом в проводнике / Finder:
# - index.html — основной терминал AEON Central Information Network
# - penrose_512_terminal.html — личный бортовой терминал LSTR-512 (в режиме эмулятора смартфона 424×852 или на весь экран)

# Способ Б: поднять локальный HTTP-сервер (рекомендуется для работы Service Worker / PWA):
python -m http.server 8080
# Основной сайт:      http://localhost:8080/
# Мобильный терминал: http://localhost:8080/penrose_512_terminal.html
```

### 2. Запуск и установка мобильного веб-приложения (`penrose_512_terminal.html`)

- **В браузере смартфона (онлайн):** перейдите по ссылке [https://main.ddhfhcprh90vq.amplifyapp.com/penrose\_512\_terminal.html](https://www.google.com/search?q=https://main.ddhfhcprh90vq.amplifyapp.com/penrose_512_terminal.html) — на экранах шириной `≤ 600px` приложение автоматически скрывает настольную рамку эмулятора и разворачивается во весь экран телефона.
- **Установка на главный экран (PWA / Офлайн-режим):**
  1. Откройте ссылку `penrose_512_terminal.html` в **Safari** (iOS) или **Chrome** (Android).
  2. Нажмите кнопку **«Поделиться»** → **«На экран "Домой"»** (*Add to Home Screen*) на iOS или меню **`⋮`** → **«Установить приложение»** / **«Добавить на главный экран»** на Android.
  3. Благодаря `manifest.json`, `sw.js` и иконке `penrose-icon.svg` терминал установится с эмблемой треугольника Пенроуза, будет открываться в полноэкранном режиме (`standalone`) без адресной строки браузера и сохранит работоспособность офлайн.
- **Управление режимами внутри мобильного приложения:**
  - Для последовательного прохождения используйте кнопку **`[ СЛЕДУЮЩАЯ ФАЗА → ]`** во вкладке `STATUS` по мере чтения записей.
  - Для мгновенного просмотра всех 5 состояний (`I.PREP` — `V.FRAGMENT`) нажмите на индикатор состояния **`ST-I // PREP`** в правой части верхней шапки терминала или перейдите во вкладку **`STATUS` → `1.4 РЕЖИМ И НАСТРОЙКИ`** и включите **Режим демонстрации**.

## Развёртывание в AWS

Публикация настроена по схеме *push → автоматическая выкатка*:

1. Исходник лежит в ветке `main` репозитория GitHub.  
2. В консоли AWS открыт **Amplify Hosting**, приложение подключено к этому репозиторию через GitHub App.  
3. Команда сборки пуста, потому что сайт статический; директория публикации — корень проекта.  
4. Каждый `git push` в `main` запускает новое развёртывание. Amplify сам выпускает сертификат и раздаёт сайт по HTTPS.

Скриншоты каждого шага приведены в отчёте.

## Оценка киберрисков

Статический сайт без бэкенда исключает целые классы угроз: нет серверной ОС под управлением владельца, базы данных, форм ввода и открытых портов. Остаются риски, связанные в основном с цепочкой поставки и настройкой облака.

| Угроза | Серьёзность | Чем опасна | Как закрыта или как закрыть |
| :---- | :---: | :---- | :---- |
| Захват аккаунта GitHub или AWS | Высокая | Подмена `index.html` и мгновенная выкатка на продакшн | 2FA на обоих аккаунтах, защита ветки `main`, минимальные права у GitHub App |
| Внедрение вредоносного кода через коммит или PR | Средняя | Скрытый скрипт попадёт на публичный сайт | Обязательный review, запрет прямых пушей в `main`, просмотр диффов |
| Утечка секретов в истории Git | Низкая | Ключи в публичном репозитории | В проекте секретов нет; при их появлении — переменные окружения Amplify и `.gitignore` |
| Отказ в обслуживании (L7) | Средняя | Недоступность сайта, расход лимитов трафика | Кеш на CloudFront, AWS Shield Standard, при необходимости AWS WAF и бюджетные алерты |
| Перехват трафика | Низкая | Подмена содержимого по пути к пользователю | HTTPS (TLS 1.2+) и управляемый сертификат |
| Отсутствие защитных HTTP-заголовков | Низкая | Clickjacking, MIME-sniffing, XSS при будущем расширении | Задать в Amplify `Content-Security-Policy`, `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy` |
| Лишние данные в публичной копии кода | Низкая | Раскрытие личных данных автора | Перед публикацией проверять файл на ФИО, почту, группу |

> Часть интерфейса использует inline-обработчики (`onclick`), поэтому строгая CSP потребует либо `unsafe-inline`, либо переноса обработчиков в `addEventListener`. Это естественный следующий шаг по усилению защиты.

## Дисклеймер

Проект учебный и некоммерческий. Вселенная, названия, термины и сюжетные элементы принадлежат создателям игры **SIGNALIS** (rose-engine). Все тексты архива написаны автором как фанатская стилизация. Разделы с пометкой о спойлерах раскрывают сюжетные детали игры.
